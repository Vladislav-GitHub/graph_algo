# Домашнее задание 1

## Файлы

- `task_1.py` - эвристическое решение первой части задачи
- `hard.gr` - сгенерированный граф для второй части задачи (`n = 10000`, `m = 50000`)
- `hard.ans` - корректный ответ для `hard.gr`, проверенный с помощью топологической сортировки

## Идея решения

Сначала программа находит компоненты сильной связности, т.к. каждый ориентированный цикл целиком находится внутри одной такой компоненты.

В каждой нетривиальной компоненте исключаются вершины с текущей входящей `in_degree` или исходящей степенью `out_degree` равной нулю не добавляя их в ответ. Потом удаляется вершина с высокой оценкой:

`in_degree * out_degree / (in_degree + out_degree)`.

Так продолжаем до устранения циклов. В конце ответ независимо проверяется алгоритмом топологической сортировки Кана. Если нашли цикл, то возвращаются все вершины графа, что даёт верное решение. Эвристика не гарантирует нахождения оптимального ответа.

## Запуск в Windows

Запустить набор тестов как обычно:

python task_1.py


Запустить решение на графе:

Get-Content hard.gr | python task_1.py > hard.ans

или

python task_1.py < hard.gr > hard.ans
